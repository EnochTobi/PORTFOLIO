# Eniabitobi Odunlami - Portfolio

A static portfolio site: plain HTML, CSS and a little JavaScript. No build step.

## Files

    portfolio-site/
      index.html      page content
      css/style.css   all styling (colors are variables at the top)
      js/main.js      makes the project list open one item at a time
      images/photo.jpg  your photo

## View it locally

Double-click `index.html`, or run `python3 -m http.server` in this folder and open http://localhost:8000.

## Publish it

Any static host works: GitHub Pages, Netlify (drag the folder onto netlify.com/drop), Vercel or Cloudflare Pages.
